## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| navegador → HTTP privado | sessão, ID/cursor/Range e conteúdo não confiável exigem validação |

| arquivo/banco → filesystem/snapshot | commits e stream não são transação comum; final/backup exigem integridade e exclusividade |
| runtime privado → Git/log/DTO | nenhum segredo/conteúdo real sai para os artefatos públicos |
